# 新生展示模式说明

## 1. 目的

迎新现场会由多位新生和领导依次体验，个人长期存档不适合作为默认演示逻辑。新生展示模式为每轮体验建立临时进度，使建筑发现、印章和任务反馈可以反复展示，同时避免覆盖原个人存档。

## 2. 当前行为

- 展示模式默认开启；
- 启动时保留个人存档的内存快照；
- 本轮地点、印章、任务和访问场景使用临时数据；
- 展示过程中不会将临时进度写入个人存档；
- 连续 `90 秒`没有检测到头显运动或手柄输入时自动复位；
- 自动复位后清空本轮进度；
- 自动取消金色路径或其他导航状态；
- 自动关闭通知书、建筑详情页、粒子和灯光反馈；
- 自动让通知书退出左手吸附；
- 如果当前不在主场景，则自动返回 Build Index 0 的迎宾场景；
- 应用正常退出时恢复原个人存档。

## 3. 活动检测

以下行为会刷新无人操作计时：

- 头显位置发生变化；
- 头显旋转超过阈值；
- 左右手柄 A/B/X/Y 按键；
- Trigger 或 Grip 输入；
- 左右摇杆输入。

## 4. 重复体验

每次自动复位后，下一位体验者可以再次：

- 发现相同建筑；
- 获得相同地点印章；
- 看到通知书蓝色发现反馈；
- 看到金色印章粒子；
- 感受双手柄震动；
- 重新完成后续小游戏和 AI 导览。

## 5. 相关代码

- `CampusShowcaseService.cs`：无人操作检测和整轮复位；
- `CampusProgressService.cs`：临时展示进度与个人存档隔离；
- `AdmissionLetterGuide.cs`：通知书状态、UI、吸附和特效复位；
- `PicoLivePreviewBootstrap.cs`：自动创建展示模式服务。
