# 虚拟校园核心交互逻辑说明

## 1. 设计原则

AI、正式 UI 和校园业务逻辑相互独立。当前阶段先保证没有正式图片、没有 Dify API 时，用户仍能完成探索、菜单、场景、任务、图鉴、导航和存档流程。

## 2. 统一交互状态

`CampusInteractionCoordinator` 维护以下模式：

- `Exploration`：普通移动、瞬移、场景快捷键和世界交互；
- `Menu`：通知书菜单交互；
- `Listening`：录音占用状态；
- `Thinking`：等待 AI，禁止重复提交；
- `Speaking`：播放回答；
- `Guiding`：导航进行中；
- `Loading`：场景加载，锁定移动和重复切换；
- `Tutorial`：新手引导保留状态。

场景加载时自动进入 `Loading`，完成后回到 `Exploration`。菜单、对话和场景快捷键不再无条件同时响应。

## 3. 地点注册

每个带 `BuildingInfo` 的对象启动后注册为 `CampusLocationDefinition`：

- `id`：稳定地点编号；
- `displayName`：显示名称；
- `description`：地点说明；
- `sceneIndex`：所属场景；
- `navigationTarget`：导航目标；
- `category`：地点分类；
- `grantsStamp`：完成后是否发放印章。

应尽量手动填写稳定 ID。建议格式：

```text
main_library
main_gate
classroom_101
exhibition_ai_history
```

## 4. 注视状态

建筑注视采用分阶段触发：

| 时间 | 行为 |
|---|---|
| 0～0.3 秒 | 过滤快速扫视 |
| 0.3 秒 | 显示建筑高亮/光柱 |
| 0.8 秒 | 确认当前上下文 |
| 1.5 秒 | 标记地点为 `Discovered` |
| 2.5 秒 | 标记地点为 `Completed`，按配置发放印章 |

同一地点通知具有 5 秒冷却，上下文离开后保留 15 秒。

地点有三级状态：

```text
Locked → Discovered → Completed
```

状态只能前进，不能因为切换场景或退出项目倒退。

## 5. 本地存档

`CampusProgressService` 将数据保存到：

```text
Application.persistentDataPath/campus_progress.json
```

保存内容：

- 最后场景；
- 已访问场景；
- 地点发现/完成状态；
- 已获得印章；
- 已完成任务；
- 提问次数；
- 新手教程是否完成。

修改进度时立即保存，正常销毁时再次保存。存档损坏时自动使用新存档，不阻止项目启动。

## 6. 任务系统

任务由 `CampusTaskService` 监听事件完成，不依赖 UI。当前任务包括：

1. 吸附录取通知书；
2. 打开录取通知书；
3. 查看校园地图；
4. 参观教室；
5. 参观展厅；
6. 发现一个地点；
7. 向 AI 提出问题；
8. 获得第一枚印章。

重复触发不会重复完成或重复发奖。

## 7. 图鉴和印章

地点达到 `Discovered` 后可以在图鉴点亮；达到 `Completed` 且地点允许发章时自动发放一次印章。任务和 UI 只读取进度服务，不直接修改数据。

## 8. 导航

`CampusNavigationService` 支持：

- 根据地点 ID 启动导航；
- 当前场景目标显示地面引导线；
- 可通过 `CampusNavigationPath` 为地点配置多个预设路径点；
- 未配置路径点时自动使用当前位置到目标的直线作为备用；
- 根据 ID 前缀推断跨场景目标；
- 跨场景加载后继续寻找目标；
- 距离目标 1.5 米时完成；
- 取消导航并清除引导线；
- 防止场景加载期间重复操作。

跨场景 ID 前缀规则：

```text
main_        → 主场景
classroom_   → 教室
exhibition_  → 展厅
```

## 9. 反馈系统

`CampusFeedbackService` 统一控制手柄震动：

- 射线首次进入按钮：轻震；
- 点击确认：短震；
- 通知书吸附：左手确认震动；
- 任务完成：双手提示震动；
- 错误反馈接口已预留。

后期音效和粒子只需接入该服务，不修改任务或菜单逻辑。

## 10. 新手教程

第一次进入依次提示：

1. 左手射线＋左 Trigger 吸附通知书；
2. 左 Grip 打开通知书；
3. 右手射线＋右 Trigger 打开校园地图。

完成后写入存档，不再自动重复。可以通过 `RestartTutorial()` 重置教程标记。

## 11. 异常恢复

`CampusRecoveryService` 每秒检查通知书：

- 坐标出现 NaN；
- 距离头显超过 8 米；
- 掉到 XR 原点以下 0.5 米。

发生异常时自动解除吸附、恢复碰撞、关闭菜单并召回到视野左下方。

## 12. 当前测试顺序

1. 用左射线点击通知书并吸附；
2. 左 Grip 打开；
3. 右射线进入菜单按钮，确认震动和高亮；
4. 打开校园地图并切换三个场景；
5. 注视带 `BuildingInfo` 的建筑至少 2.5 秒；
6. 退出 Play 后重新进入，确认存档仍存在；
7. 将通知书移动到异常位置，确认自动召回；
8. 测试 X/Y 在菜单打开和场景加载时不会误切换。
