# 高级交互开发路线与第一阶段说明

## 1. 开发原则

后续功能按照以下顺序逐步完成：

1. 优先复用现有通知书、地点、进度、射线和导航系统；
2. 先完成不依赖网络和 AI 的稳定交互；
3. 每个阶段都可以单独演示和测试；
4. Dify、ASR、TTS 和正式 UI 素材最后统一接入；
5. 不为追求效果破坏现有三个场景和 XR 初始化结构。

## 2. 第一阶段：通知书状态与印章反馈

状态：**逻辑和临时效果已完成，等待头显实机测试。**

### 发现地点反馈

地点首次进入“已发现”状态时：

- 通知书发出蓝色点光；
- 通知书纸面和封面产生一次蓝色材质脉冲；
- 效果持续约 `0.85 秒`；
- 重复注视已发现地点不会反复触发。

### 获得印章反馈

地点首次完成并发放印章时：

- 通知书发出金色点光；
- 纸面和封面产生一次金色材质脉冲；
- 通知书周围爆发 `28` 个金色粒子；
- 左右手柄同时产生短震动；
- UI 提示显示“获得探索印章 · 地点名称”；
- 已经获得的印章不会重复发放或重复触发庆祝效果。

当前使用程序生成的灯光、材质和粒子，不依赖正式美术素材。后期可以直接替换通知书模型、粒子贴图、音效和盖章图案。

## 3. 第一阶段测试方法

由于进度会保存在 `campus_progress.json`，已经完成过的地点不会再次触发首次印章效果。测试时请选择尚未完成的地点，或在明确需要重新测试时清除测试存档。

1. 启动主场景；
2. 注视一个尚未发现的建筑；
3. `1.5 秒`左右观察通知书蓝色脉冲；
4. 持续注视到 `2.5 秒`；
5. 观察金色脉冲和粒子；
6. 确认左右手柄产生一次短震动；
7. 移开视线后，建筑详情 UI 应自动关闭。

## 4. 后续阶段顺序

### 第二阶段：地图选点与金色星轨导航

- 校园地图显示可导航地点；
- 使用右手射线选择地点；
- 地面生成带流动光点的金色路径；
- 接近终点后路径消散并触发到达反馈；
- 第一版使用固定导航目标，不做自由手绘道路识别。

### 第三阶段：探索彩蛋

- 按地点数量解锁校园秘闻；
- 特定注视时长触发隐藏介绍；
- 特定参观顺序获得隐藏印章；
- 第二次进入地点显示不同提示。

### 第四阶段：空间校园广播

- 在关键区域放置空间音频触发点；
- 第一版播放本地测试语音；
- 根据进度选择不同播报内容；
- 后期将文本生成和语音合成替换为 Dify 与 TTS。

### 第五阶段：传送门式场景切换

- 地图选中教室或展厅后显示目标场景传送门；
- 显示目标名称和探索进度；
- 用户确认或进入传送门后加载场景；
- 场景切换使用淡入淡出隐藏加载过程。

### 第六阶段：Avatar 主动搭话

- 使用地点、进度和注视上下文决定发言时机；
- 先使用本地测试台词；
- 加入冷却、打断和菜单状态限制；
- 最后连接 Dify、TTS 和 Avatar 嘴型。
