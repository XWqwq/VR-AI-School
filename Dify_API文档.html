Dify 工作流编排对话型应用 API

对话应用支持会话持久化，可将之前的聊天记录作为上下文进行回答，适用于聊天/客服 AI 等场景。

目录

  1. 基础信息
  2. POST /chat-messages — 发送对话消息
  3. POST /files/upload — 上传文件
  4. GET /files/:file_id/preview — 文件预览
  5. POST /chat-messages/:task_id/stop — 停止响应
  6. GET /messages — 获取会话历史消息
  7. GET /conversations — 获取会话列表
  8. DELETE /conversations/:id — 删除会话
  9. POST /conversations/:id/name — 会话重命名
  10. GET/PUT /conversations/:id/variables — 对话变量
  11. GET /end-users/:id — 获取终端用户
  12. GET/POST /form/human_input/:token — 人工介入表单
  13. GET /workflow/:task_id/events — 工作流事件流
  14. POST /messages/:id/feedbacks — 消息反馈
  15. GET /messages/:id/suggested — 建议问题
  16. POST /audio-to-text — 语音转文字
  17. 错误码速查

1. 基础信息

基础 URL
http://localhost/v1
鉴权方式
Authorization: Bearer {API_KEY}
鉴权说明
Service API 使用 API-Key 进行鉴权。强烈建议将 API-Key 放在后端存储，而非客户端，以免泄露导致财产损失。

2. 发送对话消息

POST/chat-messages

Request Body

参数类型说明
query 必需string用户输入/提问内容
inputs 必需objectApp 定义的变量键值对。文件类型请指定包含 files 键的对象。默认 {}
response_mode 必需stringstreaming（流式，基于 SSE 逐字返回）或 blocking（阻塞，等待完成后返回）
user 必需string用户标识，需保证在应用内唯一
conversation_id 选填string会话 ID，继续之前对话时传入
files 选填array[object]文件列表。每项含 type、transfer_method、url/upload_file_id
auto_generate_name 选填bool自动生成标题，默认 true
workflow_id 选填string指定工作流版本，不提供则使用已发布版本
trace_id 选填string链路追踪 ID（也可通过 Header X-Trace-Id 传递）
trace_session_id 选填string会话分组 ID（也可通过 Header X-Trace-Session-Id 传递）

文件参数说明

字段类型说明
typestring文件类型：document / image / audio / video / custom
transfer_methodstring传递方式：remote_url（文件地址）或 local_file（上传文件）
urlstring文件地址（transfer_method 为 remote_url 时必填）
upload_file_idstring上传文件 ID（transfer_method 为 local_file 时必填）

Request 示例

curl -X POST 'http://localhost/v1/chat-messages' \
  -H 'Authorization: Bearer {api_key}' \
  -H 'Content-Type: application/json' \
  -d '{
    "inputs": {},
    "query": "What are the specs of the iPhone 13 Pro Max?",
    "response_mode": "streaming",
    "conversation_id": "",
    "user": "abc-123",
    "files": [{
      "type": "image",
      "transfer_method": "remote_url",
      "url": "https://example.com/logo.png"
    }]
  }'

created_atint消息创建时间戳

流式模式 Response

Content-Type: text/event-stream。每个块以 data: 开头，以 \n\n 分隔。

支持的 event 类型：

message message_file message_end message_replace tts_message tts_message_end workflow_started node_started node_finished workflow_finished human_input_required workflow_paused error ping
message — LLM 文本块事件
字段类型说明
task_idstring任务 ID
message_idstring消息唯一 ID
conversation_idstring会话 ID
answerstringLLM 返回文本块内容
created_atint创建时间戳
message_end — 消息结束事件
字段类型说明
task_idstring任务 ID
message_idstring消息唯一 ID
conversation_idstring会话 ID
metadataobject元数据（含 usage、retriever_resources）
workflow_started / node_started / node_finished / workflow_finished

工作流执行生命周期事件，用于追踪执行进度和调试。

字段类型说明
task_idstring任务 ID
workflow_run_idstringWorkflow 执行 ID
data.idstring执行 ID
data.workflow_idstring关联 Workflow ID
data.node_idstring节点 ID
data.node_typestring节点类型
data.titlestring节点名称
data.statusstring执行状态：running / succeeded / failed / stopped
data.outputsjson输出内容
data.elapsed_timefloat耗时（秒）
human_input_required — Human-in-the-Loop 暂停
字段类型说明
task_idstring任务 ID
workflow_run_idstringWorkflow 执行 ID
data.form_idstring表单 ID
data.node_idstringHuman Input 节点 ID
data.form_contentstring渲染后的表单内容
data.inputsarray表单输入项定义
data.actionsarray用户可选动作（id、title、button_style）
data.form_tokenstring用于提交表单的令牌
data.expiration_timetimestamp表单过期时间（Unix 秒）
流式响应完整示例

data: {"event":"node_started","task_id":"...","data":{"node_type":"start","title":"Start",...}}
data: {"event":"node_finished","task_id":"...","data":{"status":"succeeded",...}}
data: {"event":"message","message_id":"...","conversation_id":"...","answer":" I"}
data: {"event":"message","answer":"'m"}

data: {"event":"message","answer":" to"}
data: {"event":"message","answer":" meet"}
data: {"event":"message","answer":" you"}
data: {"event":"message_end","conversation_id":"...","metadata":{...}}

3. 上传文件

POST/files/upload

使用 multipart/form-data 上传文件，支持的应用所支持的所有格式。

参数类型说明
file 必需file要上传的文件
user 必需string用户标识，需与发送消息的 user 一致

Response

字段类型说明
iduuid文件 ID（用于发送消息时引用）
namestring文件名
sizeint文件大小（byte）
extensionstring文件后缀
mime_typestringMIME 类型
created_attimestamp上传时间
curl -X POST 'http://localhost/v1/files/upload' \
  -H 'Authorization: Bearer {api_key}' \
  -F 'file=@localfile;type=image/png' \
  -F 'user=abc-123'

4. 文件预览

GET/files/:file_id/preview

预览或下载已上传的文件。Query 参数 as_attachment=true 可强制下载。

5. 停止响应（仅流式模式）

POST/chat-messages/:task_id/stop
参数类型说明
task_id (path) 必需string任务 ID，从流式 Chunk 中获取
user (body) 必需string用户标识
curl -X POST 'http://localhost/v1/chat-messages/:task_id/stop' \
  -H 'Authorization: Bearer {api_key}' \
  -H 'Content-Type: application/json' \
  -d '{"user": "abc-123"}'

7. 获取会话列表

GET/conversations
参数类型说明
user 必需string用户标识
last_id 选填string当前页最后一条记录 ID
limit 选填int返回条数，默认 20，最大 100
sort_by 选填string排序：created_at / -updated_at 等
响应示例 
{
  "limit": 20,
  "has_more": false,
  "data": [{
    "id": "10799fb8-64f7-4296-bbf7-b42bfbe0ae54",
    "name": "New chat",
    "inputs": {"book": "book", "myName": "Lucy"},
    "status": "normal",
    "created_at": 1679667915,
    "updated_at": 1679667915
  }]
}

8. 删除会话

DELETE/conversations/:conversation_id
参数类型说明
conversation_id (path) 必需string会话 ID
user (body) 必需string用户标识
curl -X DELETE 'http://localhost/v1/conversations/{id}' \
  -H 'Authorization: Bearer {api_key}' \
  -H 'Content-Type: application/json' \
  -d '{"user": "abc-123"}'

响应：204 No Content

9. 会话重命名

POST/conversations/:conversation_id/name
参数类型说明
name 选填string名称，auto_generate 为 true 时可不传
auto_generate 选填bool自动生成标题，默认 false
user 必需string用户标识

10. 对话变量

GET/conversations/:conversation_id/variables

获取特定对话中捕获的变量。Query: user（必需）、last_id、limit、variable_name。

PUT/conversations/:conversation_id/variables/:variable_id

更新对话变量值。Body: {"value": "新值", "user": "abc-123"}。

11. 获取终端用户

GET/end-users/:end_user_id

通过终端用户 ID 获取用户信息。

12. 人工介入表单 (Human-in-the-Loop)

GET/form/human_input/:form_token

获取待处理表单。返回 form_content、inputs、user_actions、expiration_time。

POST/form/human_input/:form_token

提交表单。Body: {"inputs": {"field": "value"}, "action": "approve", "user": "abc-123"}。

13. 工作流事件流（恢复后继续订阅）

GET/workflow/:task_id/events
参数类型说明
task_id (path) 必需stringworkflow_run_id
user (query) 必需string终端用户标识
include_state_snapshot 选填bool先回放持久化状态快照
continue_on_pause 选填bool暂停时保持连接直到 finished

14. 消息反馈（点赞）

POST/messages/:message_id/feedbacks
参数类型说明
rating 必需stringlike / dislike / null（撤销）
user 必需string用户标识
content 选填string反馈信息

另外 GET /app/feedbacks?page=1&limit=20 可获取应用的消息反馈列表。

15. 建议问题列表

GET/messages/:message_id/suggested

获取下一轮建议问题。Query: user（必需）。返回 {"result": "success", "data": ["问题1", "问题2", ...]}。

16. 语音转文字

POST/audio-to-text

使用 multipart/form-data 上传语音文件。

参数类型说明
file 必需file语音文件（mp3/mp4/mpeg/mpga/m4a/wav/webm，≤15MB）
user 必需string用户标识

返回：{"text": "转文字结果"}

17. 错误码速查

状态码code说明
400invalid_param传入参数异常
400app_unavailableApp 配置不可用
400provider_not_initialize无可用模型凭据配置
400provider_quota_exceeded模型调用额度不足
400model_currently_not_support当前模型不可用
400workflow_not_found指定工作流版本未找到
400draft_workflow_error无法使用草稿工作流版本
400workflow_id_format_error工作流 ID 格式错误，需 UUID
400completion_request_error文本生成失败
400no_file_uploaded必须提供文件
400too_many_files目前只接受一个文件
401unauthorizedAPI Key 无效或缺失
404-对话不存在 / 文件未找到
413file_too_large文件太大
415unsupported_file_type不支持的文件类型
500-服务内部异常
